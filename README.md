# 🏠 PrimeNest — Architectural Luxury Real Estate Reserve

An architectural luxury real estate website built with **React Three Fiber**, **Three.js**, **Framer Motion**, and **Tailwind CSS**.

Featuring an animated **3D Architectural Complex** with running train, glowing shop windows, golden dust particles, sunset golden hour lighting, time-of-day switcher, and private viewing inquiry.

### Quick Start
```bash
npm install
npm run dev
```
Visit `http://localhost:3004`
